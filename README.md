# 星迹 · GPS 工具箱

个人自用的 Android 原生定位工具。目标设备：红米 K70 / Android 16 / 澎湃 OS 3。

**代码在 GitHub，测试及编译只在 GitHub 托管 Actions 上运行。** 不需要电脑安装开发环境。当前为 0.1.0 真机验证预览版。

## 安装

打开 Actions → Android APK → 最新成功的运行 → Artifacts → `StarTrace-installable-apk`。解压后安装 `.apk`。私有仓库需要登录有权限的 GitHub 账号。

APK 使用固定的个人发布密钥签名，不是每次变化的临时 debug 签名。包名 `com.meteorsss.startrace`。请保留同一仓库签名 Secret，后续正常覆盖更新；卸载会删除本地记录。

## 功能

- 实时仪表：WGS84 经纬度、估计水平精度、速度、椭球高度、运动方位、数据年龄、本次首次定位用时。
- 卫星：天空图，按系统和卫星编号去重计数，最强 20 条信号明细及设备提供的频率。
- 轨迹：手动开始、暂停、继续、停止；定位前台服务及通知操作；SQLite 实时保存；异常中断恢复标记。
- 本地历史：相对轨迹预览、距离/时间/平均速度、重命名和删除。
- 导出：有效轨迹 GPX、全部原始点 CSV；保留分段，过滤不修改原始数据。
- 收藏地点：当前位置或输入 WGS84 坐标、名称和备注、到目标的直线距离及真北方向指引。
- 工具：磁北指南针、大字速度表、可选常亮、坐标格式转换、球面近似两点测距、定位诊断。
- 深浅色主题，中文界面，无 Google Play 服务依赖。

## 真实的数据边界

- **不含道路/卫星影像底图、道路导航、离线地图包、模拟定位或坐标系转换。** 轨迹画面只是北向上的相对轨迹图。
- 定位精度是系统估计，不是保证误差。过期超过 15 秒的位置不用于实时仪表和保存地点。
- 显示的高度是 WGS84 椭球高，**不是平均海平面海拔**。GPX 以自定义扩展保存此高度，不误写成标准 `ele`。
- 采样请求约 1 秒；实际回调频率由系统和设备决定。暂停、超过 30 秒缺失或拒绝的点会分段。
- 高于 80 米估计误差、明显跳点、模拟位置和过期位置不计入有效轨迹。CSV 保留收到的这些原始数据及标记。
- 里程使用抗漂移过滤，是估计值，不适用于计费、测绘或安全关键导航。
- 方向传感器受磁性物体影响。目标方向使用磁偏角近似修正为真北；不是避障导航。
- 卫星频率/信号字段以实际设备提供为准，未提供时不猜测。

## 隐私与权限

无账号、广告、云同步、分析 SDK，Manifest **没有 INTERNET 和 ACCESS_BACKGROUND_LOCATION 权限**。数据只保存于应用私有目录；系统云备份和设备迁移均排除应用数据。导出由系统文件选择器决定保存目标，导出文件包含精确位置，分享前请核对。

只在用户开启功能时请求精确位置。开始轨迹时请求通知权限，随后使用 `location` 类型前台服务。通知被拒绝时仍可录制，但通知栏操作入口可能不可见。

## 红米真机验收

1. 打开仪表，授予精确位置，到室外确认坐标、数据年龄和精度；拒绝/撤销权限不应崩溃。
2. 检查卫星图、编号、参与定位计数及频率是否由 K70 实际提供。
3. 静止 5 分钟，观察漂移；步行 10 分钟，验证距离和轨迹分段。
4. 记录时熄屏 15–30 分钟，再打开，检查是否连续；必要时调整澎湃 OS 的应用电池策略。
5. 暂停、移动、继续：不应把暂停路段计入；关闭定位后应显示断点。
6. 导出 GPX 与 CSV，检查时间、坐标、分段、原始点数；不要把真实测试轨迹上传公共仓库。
7. 强制停止再打开：已存数据应标记中断，不暗中自动重启记录。
8. 安装后续版本，确认可覆盖更新且历史保留。

云端编译与模拟器测试不代表上述真机测试已经通过，尤其无法证明澎湃 OS 后台稳定性、真实卫星信号和方向精度。

## 云端构建与签名

- Java 17、AGP 8.13.2、Gradle 8.13、compile/target SDK 36、min SDK 33（Android 13）。
- 主分支推送自动执行单元测试、Android Lint、release APK 编译、签名校验和隐私权限检查。
- 单独的 Android 16 模拟器任务检查页面渲染、SQLite/GPX/CSV、录制服务开始/暂停/继续/停止；截图与日志保存在构建产物中。
- `SIGNING_BUNDLE` 为 GitHub Actions Secret，含发布签名材料。密钥在云端生成，首次仅输出 GitHub 公钥加密的密文，经 API 存入 Secret；没有明文下载到开发电脑。
- **不要重新初始化或删除 SIGNING_BUNDLE**，否则现有 APK 无法由新密钥直接覆盖升级。当前唯一持久副本在仓库 Secret，应另行安排经过授权的加密离线备份。
- 签名 Secret 仅由构建任务读取；解密后的密钥只存在临时云端运行器，构建结束删除。
- Actions artifacts 有保留期，正式版本可发布到私有 Releases。私有 Actions 额度/费用由账号方案决定，不主动开启付费资源。
